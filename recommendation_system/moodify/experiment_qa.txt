pca 的使用時機，本身是一個非監督式的線性降維方法。 (程式碼的預設上，會直接降到feature的大小維度。)
方法：
    對共變異數矩陣進行特徵分解，以得出數據的主成分（即特徵向量）與它們的權值（即特徵值）
    在原數據中除掉最小的特徵值所對應的成分，使得降維失去最少的訊息

SVC 在大型資料集上運行緩慢的原因
Support Vector Machine (SVM)，特別是使用 RBF 核心 (kernel) 時，在訓練過程中其時間複雜度與樣本數量 N 的關係大約是 O(N 3
 ) 或 O(N 2)，具體取決於實現細節。這意味著當你的資料集樣本數量 N 變大時，訓練時間會急劇增長。

主要有以下幾個原因：

核矩陣的計算： RBF 核心需要計算所有樣本對之間距離的核矩陣（Gram matrix）。這個矩陣的大小是 N×N，計算量為 O(N 
2
 )。

尋找支援向量： SVM 的核心目標是找到一個最佳的超平面來區分資料點，這個過程涉及到求解一個二次規劃 (Quadratic Programming, QP) 問題。這個問題的複雜度也與樣本數量相關，特別是在樣本數量很大時，求解的成本很高。

記憶體消耗： N×N 的核矩陣需要大量的記憶體來儲存，對於非常大的資料集，可能會超出記憶體限制。

因此，對於數萬或數十萬級別的樣本，標準的 SVC（尤其搭配 RBF 核心）可能會變得非常慢，甚至無法在合理的時間內完成訓練。

LinearSVC：SVM 的線性版本
LinearSVC 是 SVC 的一個變種，它專門用於線性可分的數據，並使用線性核（kernel='linear'）。

原理： LinearSVC 旨在尋找一個線性分類器（一條直線或一個超平面）來分隔不同類別的資料點。它與標準 SVC 處理線性分類任務的方式有些不同，它使用了 liblinear 函式庫，該函式庫對線性分類問題進行了優化。

優勢：

速度快： 相較於 RBF 核心的 SVC，LinearSVC 在大型資料集上的訓練速度快得多。它的時間複雜度大約是 O(N×d)，其中 d 是特徵數量。

記憶體效率高： 它不需要計算核矩陣，因此記憶體消耗也較小。

缺點：

僅適用於線性可分資料： 如果你的資料不是線性可分的（即無法用一條直線或超平面完美分隔），LinearSVC 的表現可能不如 RBF 核心的 SVC。

適用場景：

當資料集非常大，且你懷疑資料是線性可分或近似線性可分時。

需要快速的分類器作為基準模型時。
